### Ordinary lesson checks — M07-U04

1. **Full prompt:** “A workflow has two jobs: 1. Deploy and test a candidate without production traffic. 2. Promote the candidate to receive production traffic. Which job should reference the approval-protected production GitHub environment, and why?”
   - **Initial learner response:** “The promote job. Because it requires approval before being exposed to production traffic”
   - **Tutor feedback:** Correct—the promotion job waits before changing production traffic; deployment and testing can occur earlier without exposure.
   - **Follow-up:** No retry. Independent approval placement within the taught scenario.
2. **Full prompt:** “Your staging job uses OIDC, but its Azure identity has permission to modify both staging and production endpoints. Does OIDC alone provide staging–production isolation? What would you change?”
   - **Initial learner response:** “No. it willneed to have some permissions like RBAC”
   - **Tutor feedback:** Yes, OIDC alone does not isolate; it handles authentication, RBAC authorization. Permissions already exist and are too broad: use separate identities, scope staging to staging resources, and use production permissions in the protected promotion job.
   - **Follow-up:** No learner follow-up or independent recovery reported. The separate-identity and narrowed-scope solution was tutor-supplied; detailed RBAC application is not established.
3. **Full prompt:** “A release comes from main, but its staging deployment tests failed. A teammate says, ‘It’s from the allowed branch, so we can promote it.’ Would you proceed? What evidence should the reviewer require?”
   - **Initial learner response:** “No. there might be a reason why staging fails, we need to investigate as it might be a more costly problem in Production”
   - **Tutor feedback:** Correct—main does not override failed tests; investigate and resolve failure, then require passing staging deployment-test results before promotion. Feedback was delivered in the quiz-offer question tool.
   - **Follow-up:** No retry. The learner independently rejected promotion and reasoned about investigation and production risk; precise passing-test evidence was reinforced by the tutor.
