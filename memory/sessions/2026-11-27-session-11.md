### Ordinary lesson checks

1. **Prompt:** 'You want to compare prompt v1 with prompt v2, but your uploaded dataset contains only v1’s saved answers. If you start a second evaluation run named "prompt-v2-evaluation" against that same dataset, will it evaluate v2’s behavior? What would need to change?'

   **Initial learner response:** 'we need to have the v2 evaluation with the v2's saved answers'.

   **Feedback:** Exactly: v2 saved answers are needed; naming does not change the responses. Keep questions, supporting context, evaluators and settings consistent. Saved-response identity was independent; fair-comparison elaboration was tutor-supplied. No retry.

2. **Prompt:** 'the run eventually reports completed, but its results include answers that invent refund exceptions. What does completed tell you, and should those results permit release?'

   **Initial learner response:** 'completed means the run finished, but not the actual result, which in this case has to be evaluated against thresholds, and requirements before being released. It seems to have failed the groundedness test.'

   **Feedback:** Correct execution versus quality and release interpretation. The groundedness diagnosis fits if the supplied policy context does not support the exceptions; policy evidence is needed. Independent execution/release interpretation; groundedness inference qualified by tutor. No retry.

3. **Prompt:** A dataset contains only `{"Question":"Can I get a refund after 35 days?","Answer":"Yes, refunds are allowed for 60 days.","ExpectedAnswer":"No, this purchase is outside the refund window."}`. 'You want to evaluate whether the answer is supported by the actual refund policy, using groundedness. What information must you add, and which groundedness input should it map to? No need to write Python syntax.'

   **Initial learner response:** 'It will require the context parameter'.

   **Feedback:** Yes, context must contain the actual refund policy: add policy text and map its field to context; expected answer is not a substitute. The learner independently named the input but did not specify actual policy text; the content remedy was tutor-supplied. No retry; fully independent mapping transfer was not demonstrated.
