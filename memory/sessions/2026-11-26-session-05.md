### Ordinary lesson checks

1. **Prompt:** “Suppose that smaller model answers routine questions well but gives misleading guidance on ambiguous access problems. Would you immediately switch to a larger model, or investigate something else first? What would you look at?”

   **Initial response:** “No. We can try to ground the knowledge by implementing RAG, as a tool for the model. If this does not work, then we can try to use the larger models. Smaller modles are better with more guided/defined instructions.”

   **Feedback:** Sensible to diagnose before increasing size; clear instructions help both sizes. RAG helps missing or poorly retrieved information, but if the correct passage is already supplied, investigate prompt and reasoning capability; compare the same test cases. No separate retry.

2. **Prompt:** “Your company changes its access policy weekly, and the agent must answer in a consistent, friendly support style. Would you start with RAG, fine-tuning, or both—and why?”

   **Initial response:** “RAG, given it is necessary to retrieve current facts.”

   **Feedback:** Correct starting point; a prompt can initially guide friendly tone, and fine-tuning is not required merely for consistency. No retry.

3. **Prompt:** “After a prompt change, the agent answers a routine password-reset question correctly. Is that enough to release the change? What else would you check?”

   **Initial response:** “I will try to test it a bit more times to check for consistency. I will also check for the the groundedness of the answer, did it retrive the correct documents”

   **Feedback:** Consistency and right retrieval are useful, but check faithful use and unsupported claims as well as varied ambiguous, refusal and escalation cases, not only repetitions; smoke then broader rubric evaluation. Learner said “Cool.” No independent ordinary-check retry; added release coverage was tutor-supplied.

### [Q01](../../lessons/02-genaiops/01-plan-and-prepare/quizzes.md#quiz-2026-11-26-session-05-q01) — Model selection; easy; single-answer; G01-U03

**Prompt:** Question 1/5 — Easy. Select one answer. Which principle should guide model selection for a focused, high-traffic support agent?

- A. Choose the largest model — Prioritize maximum model size over other constraints.
- B. Choose by quality and constraints — Test whether the model meets the rubric within cost and latency requirements.
- C. Choose the smallest model — Prioritize minimum model size regardless of evaluation results.

**Initial selection:** B. **Key:** B. **Outcome:** correct. **Explanation:** Match the model to the task and test against the rubric and constraints. A ignores cost and latency; C ignores sufficient quality.

### [Q02](../../lessons/02-genaiops/01-plan-and-prepare/quizzes.md#quiz-2026-11-26-session-05-q02) — Changing facts; medium; single-answer; G01-U03

**Prompt:** Question 2/5 — Medium. Select one answer. An agent must answer questions about a product catalog that changes daily. Which approach best supplies those changing facts without retraining the model for each update?

- A. Fine-tune on today's catalog — Train the model using a snapshot of product information.
- B. Adjust the friendly-tone prompt — Change the instructions governing response style.
- C. Retrieve catalog data with RAG — Supply relevant external product information when generating answers.

**Initial selection:** C. **Key:** C. **Outcome:** correct. **Explanation:** RAG retrieves external facts; its pipeline still needs current data. A can become stale; B changes style rather than factual access.

### [Q03](../../lessons/02-genaiops/01-plan-and-prepare/quizzes.md#quiz-2026-11-26-session-05-q03) — RAG and fine-tuning; medium; multiple-answer; G01-U03

**Prompt:** Question 3/5 — Medium. Select two answers. Which TWO statements correctly describe RAG and fine-tuning?

- A. Fine-tuning can adapt behavior — Training examples can shape a consistent style or specialized skill.
- B. RAG guarantees grounded answers — Retrieving documents ensures every generated claim is supported.
- C. They can be combined — Use retrieval for current facts and fine-tuning for behavior.
- D. Fine-tuning keeps facts current — Once trained, a model automatically incorporates later policy updates.

**Initial selections:** B, C. **Key:** A, C. **Outcome:** incorrect. **Explanation:** A and C describe complementary roles. B falsely guarantees faithful use of evidence; D falsely implies automatic learning of later updates. The initial selection remains unchanged after feedback.

**Follow-up:** Tutor explained that finding evidence and using it faithfully are separate checks. Q04 was answered correctly after that explanation; it is scaffolded transfer, not a retry or an independent pre-feedback correction of Q03.

### [Q04](../../lessons/02-genaiops/01-plan-and-prepare/quizzes.md#quiz-2026-11-26-session-05-q04) — Diagnose answer generation; hard; single-answer; G01-U03

**Prompt:** Question 4/5 — Hard. Select one answer. Logs show that the agent received the correct access-policy passage, but its answer gives instructions that contradict that passage. What is the best next investigation?

- A. Refresh the policy index only — Treat stale source data as the established cause.
- B. Inspect how the answer is generated — Check prompt instructions and interpretation of supplied context, then evaluate a correction.
- C. Release because retrieval worked — Treat successful document retrieval as sufficient evidence of answer quality.

**Initial selection:** B. **Key:** B. **Outcome:** correct. **Explanation:** Correct context reached the model, so investigate its use of that context. A assumes a data problem despite the evidence; C overlooks the incorrect answer. Tutor application of the source's grounding and optimization principles, delivered after Q03 feedback; scaffolded transfer.

### [Q05](../../lessons/02-genaiops/01-plan-and-prepare/quizzes.md#quiz-2026-11-26-session-05-q05) — Release evaluation; medium; multiple-answer; G01-U03

**Prompt:** Question 5/5 — Medium. Select two answers. Before releasing a substantial prompt change, which TWO actions best support the lesson's optimization loop?

- A. Repeat only one successful request — Use consistency on that request as the entire release check.
- B. Run quick smoke tests — Check a small set of known cases for obvious regressions.
- C. Judge only the improved tone — Accept the change if answers sound friendlier.
- D. Run broader rubric-based evaluation — Evaluate representative requests, including ambiguous and boundary cases.

**Initial selections:** B, D. **Key:** B, D. **Outcome:** correct. **Explanation:** Smoke tests offer fast feedback and broader rubric-based evaluation supports release decisions. A lacks coverage; C ignores other quality requirements. This recognition followed ordinary-check teaching, not an independent pre-feedback construction of release coverage.
