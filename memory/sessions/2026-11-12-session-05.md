## Topics discussed

Default compute is overridden by a step-specific target; the default datastore is output storage, not compute. Printing inspects a job; `jobs.create_or_update` submits it, but submission is not successful completion. Diagnose pipeline-configuration failures via the parent and component failures via the relevant child logs. `JobSchedule` and `RecurrenceTrigger` associate frequency and interval with recurring runs; disable a schedule before deletion. A time schedule is not a drift detector and scheduled training does not itself deploy a model; explicit deployment steps and validation gates are needed. These last clarifications were tutor-supplied.

Python SDK v2 examples were source-adapted illustrations, not executed. They require `azure-ai-ml`, an authenticated `MLClient`, configured resources, permissions and compatible environments; no installed SDK version was verified.
