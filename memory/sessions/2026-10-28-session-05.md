### Q02 — Mean aggregation and one row

[Persisted Q02](../../lessons/01-mlops/01-get-started-with-machine-learning/quizzes.md#quiz-2026-10-28-session-05-q02).

M01-U03; medium; single answer. Prompt: “Machine A reports valid temperatures of 16°C, 20°C, and 24°C during the same minute. Training requires one row per machine per minute containing the average temperature. Which output meets the requirement?”

- A. Three rows: 16°C, 20°C, 24°C (Keep each original reading as a separate row.)
- B. One row: 24°C (Store highest reading for minute.)
- C. One row: 20°C (Store mean of three readings.)
- D. One row: 60°C (Store sum of three readings.)

Initial selection: C, One row: 20°C. Key: {C}. Outcome: correct. Explanation: (16+20+24)/3 = 20, with one row; A has the wrong granularity, B the maximum, D the sum. This demonstrates selection of the correct mean and row, not a separately shown calculation process.

### Q03 — ETL order

M01-U03; medium; single answer. Prompt: “A pipeline extracts sensor readings, converts them into the required training table, and then loads that prepared table into storage. Which processing order is this?”

- A. ELT (Extract, load, then transform.)
- B. ETL (Extract, transform, then load.)
- C. Extract and load only (Move data without transforming it.)

Initial selection: B, ETL. Key: {B}. Outcome: correct. Explanation: transformation precedes loading; A reverses this order and C omits transformation.
