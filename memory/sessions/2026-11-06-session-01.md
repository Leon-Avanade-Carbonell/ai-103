### [Q01 — Search-space definition](../../lessons/01-mlops/04-hyperparameter-tuning/quizzes.md#quiz-2026-11-06-session-01-q01)

Easy; single-answer. **Prompt:** What does a hyperparameter search space define? Select one answer.
- A. The best values already found — The final tuning result.
- B. The candidate values allowed — The possibilities available to the tuning process.
- C. The number of concurrent trials — How many training runs execute simultaneously.

Initial selection B; correct set B; correct. **Explanation:** The search space defines candidate values, not the result of tuning (A) or concurrency limits (C).

### [Q02 — Exact discrete choices](../../lessons/01-mlops/04-hyperparameter-tuning/quizzes.md#quiz-2026-11-06-session-01-q02)

Easy; single-answer. **Prompt:** Which definition allows batch sizes of exactly 16, 32, or 64? Select one answer.
- A. Uniform(16, 64) — A continuous distribution between the bounds.
- B. Normal(mu=32, sigma=16) — A distribution centered at 32.
- C. Choice(values=[16, 32, 64]) — An explicit list of candidates.

Initial selection C; correct set C; correct. **Explanation:** Choice permits only the listed values. Uniform allows intermediate values; Normal allows values outside the list and has no hard bounds.

### [Q03 — Positivity through exponentiation](../../lessons/01-mlops/04-hyperparameter-tuning/quizzes.md#quiz-2026-11-06-session-01-q03)

Medium; multiple-answer. **Prompt:** Which distributions produce strictly positive values by exponentiating sampled values? Select two answers.
- A. LogNormal — A logarithmic distribution.
- B. Normal — An ordinary normal distribution.
- C. Uniform with bounds −1 and 1 — A continuous bounded distribution.
- D. LogUniform — Another logarithmic distribution.

Initial selections A, D; correct set A, D; correct exact set. **Explanation:** LogNormal and LogUniform exponentiate samples. Normal can produce nonpositive values, and the stated Uniform range includes them.

### [Q04 — Equal multiplicative bands](../../lessons/01-mlops/04-hyperparameter-tuning/quizzes.md#quiz-2026-11-06-session-01-q04)

Medium; single-answer. **Prompt:** A learning rate should have equal probability of falling in each band: 0.0001–0.001, 0.001–0.01, and 0.01–0.1. Which definition fits? Select one answer.
- A. Uniform(0.0001, 0.1) — Uniform sampling in linear space.
- B. LogUniform(ln(0.0001), ln(0.1)) — Uniform sampling in natural-log space.
- C. Choice(values=[0.0001, 0.001, 0.01, 0.1]) — Sampling only four listed values.

Initial selection B; correct set B; correct. **Explanation:** These factor-of-10 bands have equal widths in log space. Uniform favors the widest linear band; Choice limits values to four points instead of sampling throughout the bands.

### [Q05 — Linear interval probability](../../lessons/01-mlops/04-hyperparameter-tuning/quizzes.md#quiz-2026-11-06-session-01-q05)

Medium; single-answer. **Prompt:** You use Uniform(min_value=0.001, max_value=0.1). Which interval has the greatest probability of receiving a sample? Select one answer.
- A. 0.001–0.01 — The lower interval.
- B. Both intervals equally — Equal probability for each interval.
- C. 0.01–0.1 — The upper interval.

Initial selection C; correct set C; correct. **Explanation:** The upper interval is ten times wider in linear space (0.09 versus 0.009), so has ten times the probability. Equal probability for these bands would describe log-space sampling, not Uniform.

### [Q06 — Normal parameters](../../lessons/01-mlops/04-hyperparameter-tuning/quizzes.md#quiz-2026-11-06-session-01-q06)

Medium; multiple-answer. **Prompt:** What do mu and sigma specify in Normal(mu, sigma)? Select two answers.
- A. mu is the hard minimum — A lower bound on all sampled values.
- B. sigma is the standard deviation — The distribution's spread.
- C. mu is the mean — The distribution's center.
- D. sigma is the quantization step — The spacing between discrete values.

Initial selections C, B in returned order; set B, C; correct set B, C; correct exact set. **Explanation:** mu is the mean, not a hard bound; sigma is the standard deviation. Quantized distributions use q as their step.

### [Q07 — Script constraints and quantization](../../lessons/01-mlops/04-hyperparameter-tuning/quizzes.md#quiz-2026-11-06-session-01-q07)

Hard; single-answer. **Prompt:** A proposed batch-size search rounds samples to multiples of 16 over a range that includes 16 through 64. The script accepts only 16, 32, or 64. What is the best correction? Select one answer.
- A. Use Choice(values=[16, 32, 64]) — Declare the accepted values explicitly.
- B. Keep rounding to multiples of 16 — Retain the proposed quantized search.
- C. Use Uniform(16, 64) — Replace rounding with continuous sampling.

Initial selection A; correct set A; correct. **Explanation:** Choice enforces the exact constraint. Rounding can produce 48; Uniform allows other intermediate values. Applied tutor scenario.

### [Q08 — LogUniform bounds troubleshooting](../../lessons/01-mlops/04-hyperparameter-tuning/quizzes.md#quiz-2026-11-06-session-01-q08)

Hard; single-answer. **Prompt:** Azure ML defines LogUniform(a, b) as exp(Uniform(a, b)). A developer passes a=0.001 and b=0.1, expecting learning rates between 0.001 and 0.1. What is actually the issue? Select one answer.
- A. LogUniform can return negative values — Exponentiation may change the sign.
- B. It returns only the two bounds — Intermediate values cannot be sampled.
- C. The output is between exp(0.001) and exp(0.1) — Raw positive bounds were supplied instead of their natural logarithms.

Initial selection C; correct set C; correct. **Explanation:** LogUniform exponentiates its uniformly sampled log-space values. Supply ln(0.001) and ln(0.1) for the intended output range. Outputs are positive and span a continuous range, ruling out A and B.
