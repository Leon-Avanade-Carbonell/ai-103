### Ordinary lesson checks

1. **Prompt:** 'Two reviewers score the same response: one gives it 5, the other 3. Their only written guidance is “score how helpful the answer is.” Before using those scores to compare agent variants, what would you change about the evaluation process—and why?'

   **Initial learner response:** 'You should have a defined rubric on how the response is scored / evaluated; so there is guidance for the evaluators what "good" means'

   **Feedback:** Correct; a shared rubric with specific criteria, levels and examples improves comparability. The tutor then explained calibration using 5–8 varied responses, independent scoring without intended scores, comparing and discussing differences greater than one point, refinement and repetition, and retention in a repository. The learner did not independently design that procedure.

2. **Prompt:** 'Using our returns-assistant example, two evaluators still disagree after reading the rubric: Reviewer A gives 5 because the answer lists every replacement step. Reviewer B gives 2 because several steps contradict the supplied returns policy. What would you clarify in the evaluation criteria so completeness doesn’t hide unsupported claims?'

   **Initial learner response:** 'I will try to add some groundedness evaluations as well, and as a guide to the evaluators.'

   **Feedback:** Correct direction: a separate groundedness rubric checks policy support and intent resolution checks whether the task was addressed. The tutor clarified that accuracy must also affect intent resolution, so complete but incorrect steps are not automatically highest-scoring. The detailed metric interplay was tutor-supplied, not independently demonstrated.

3. **Prompt:** 'A team scores 10 responses: 6 have exact agreement. 3 more have scores within one point. 1 has divergent scores. Does this meet the source’s agreement target? And does that result tell us the agent’s answers are high quality?'

   **Initial learner response:** 'Yes, with the at least 80%-ish agreement target.'

   **Feedback:** The first part is correct; the tutor supplied 9/10 = 90% and explained that agreement measures scoring consistency, not quality, using the example of all raters assigning 1/5. The initial answer did not address quality or independently calculate 90%.

4. **Scaffolded follow-up prompt:** 'if everyone agrees the answers are poor, what does that tell you about the evaluators—and about the agent?'

   **Actual learner response:** 'I think it says that the score is bad, and that the evaluators agree with that sentiment, which means the agent needs to be work on.'

   **Feedback:** Correct: consistent scoring alongside weak agent performance on the evaluated criteria. This is scaffolded recovery, not independent transfer.
