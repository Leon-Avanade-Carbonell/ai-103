Tutor repeated the context: blue version 7 receives 100% of normal traffic, green version 8 receives 0%; “Your colleague says: ‘We need to give green production traffic before we can test it.’ Do you agree? What would you do to test green while normal users continue receiving predictions from blue?”

Initial learner answer: “We need to set the traffic to v7 (80%) and v8 (20%)”. Tutor feedback: 80/20 sends 20% of normal users to green, a rollout rather than an isolated test.
