### Ordinary lesson checks — M04-U03

1. **Prompt:** “Suppose you have four batch-size choices and five learning-rate choices, but a budget of only ten trials. Can grid sampling cover every combination? Explain briefly.”
   - **Initial learner response:** “Yes, because the sample will be choosing with only those choices.”
   - **Tutor feedback:** The allowed-choice part is right, but 4 × 5 = 20 combinations; ten trials can cover at most half. Distinguished allowed values from coverage.
   - **Follow-up:** No immediate independent retry. Later quiz Q02 correctly counted a new 3 × 4 grid; Q08 applied limited-budget method selection.
2. **Prompt:** “With those same 20 possible combinations and only ten trials, would switching to random sampling guarantee testing all 20? Why or why not?”
   - **Initial learner response:** “It will not guarantee testing of all 20, but your values will be coming from any 10 of those 20 values”.
   - **Tutor feedback:** Noncoverage is correct, but ten distinct combinations are not guaranteed; repeats can reduce the unique count and each trial selects a combination rather than a single value.
   - **Follow-up:** Q03 supported constraints and nonexhaustiveness. Possible repeats/unique-count limitation was tutor-supplied and not explicitly independently checked.
3. **Prompt:** “Training each model is expensive, and you want previous trial results to guide which settings you try next. Which sampling method would you choose, and why?”
   - **Learner question instead of an answer:** “If the batch_size = 3 , 10, 15, and you have a random sobol with a value (seed) of 4. Is that valid setting? How will it affect the learning_rate and batch_size?” Not scored as an answer to the prompt.
   - **Tutor response:** S2 accepts integer seed 4; the Choice list is valid if the script accepts it. Seed controls the sequence for both sampled tunables, not a value, bounds or count; a fixed learning rate is not tuned. Exact samples were not invented. An illustrative, unrun configuration used Choice `[3, 10, 15]`, Uniform `.001–.1`, and `RandomSamplingAlgorithm(rule="sobol", seed=4)`.
   - **Follow-up:** Check 5 and quiz Q07/Q08 separately addressed Bayesian selection; Q05/Q06 addressed seed scope.
4. **Prompt:** “If you change only the seed from 4 to 99, could that make the sampler choose batch size 99? What would change instead?”
   - **Initial learner response:** “No, it seems not. I might change the batch_size instead?”
   - **Tutor feedback:** No 99 unless allowed; editing the Choice list changes allowed batch sizes, whereas changing the seed changes the sampling sequence within the same list and may change specific batch/learning-rate selections. Menu versus selection-sequence analogy was scaffolded.
   - **Follow-up:** Q05 D and Q06 A,C independently selected after clarification support seed/scope distinction.
5. **Prompt:** “Which method uses previous trials’ performance to guide the next choices—grid, Sobol, or Bayesian?”
   - **Initial learner response:** “It would be Bayesian, provided your batch is Uniform, Choice, or QUniform.”
   - **Tutor feedback:** Bayesian and the restriction are correct; restriction applies to every tuned hyperparameter, not only batch; Choice is preferable for an exact integer batch list.

### [Q03 — Grid/random constraints](../../lessons/01-mlops/04-hyperparameter-tuning/quizzes.md#quiz-2026-11-06-session-02-q03) — medium, multiple-answer, S1

Prompt: Which statements about grid and random sampling are correct? Select two answers.
- A. Grid supports continuous intervals — A grid can exhaust an unrestricted continuous interval.
- B. Grid requires discrete hyperparameters — Each hyperparameter must have discrete candidates.
- C. Random guarantees exhaustive coverage — Every possible combination is guaranteed to be tested.
- D. Random supports mixed search spaces — Discrete and continuous hyperparameters can be combined.

Initial: D, B (returned order), set B,D. Key: B,D. Outcome: correct, exact set. Explanation: Grid requires discrete candidates, while random supports mixed spaces. Grid cannot exhaust continuous intervals (A); random does not guarantee exhaustive coverage (C). Follow-up: None.

Prompt: Which statements about a seeded Sobol sweep are justified? Select two answers.
- A. Sampling can be reproduced — With the same seed and sampling configuration, the sampling sequence is reproducible.
- B. Training results must be identical — The sampling seed controls all randomness in model training.
