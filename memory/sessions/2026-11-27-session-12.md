### Ordinary lesson checks

1. **Prompt:** 'Tutor-created scenario: a prompt PR produces results.json with "passed": false. The workflow successfully posts “❌ FAILED” on the PR, but every Actions step finishes successfully. Would this reliably prevent merging? What would you add or change?'

   **Initial learner response:** 'I will add a gated condition where the CI/CD stops when the evaluation fails.'

   **Feedback:** Yes, make the failed quality decision fail the CI check. The tutor supplied the nonzero exit-code implementation and branch protection/ruleset required-check condition; failed checks may otherwise be bypassed. The tutor distinguished access/execution failure from measured quality failure. No follow-up response. Failure gating was independently identified; repository enforcement details were not independently demonstrated.

2. **Prompt:** 'a workflow authenticates successfully to Azure, but evaluation fails with an authorization error when accessing its dataset. Would you investigate federated trust, Azure resource permissions, or the prompt’s quality first—and why?'

   **Initial learner response:** 'Azure resource permissions because there is an auth error. RBAC policy for the user (workflow)'

   **Feedback:** Correct: investigate RBAC/resource permissions because authentication succeeded. The tutor clarified that the workflow principal is usually a service principal or managed identity and that scope matters; authentication errors instead point to token/identity configuration. No follow-up or execution evidence.

3. **Prompt:** 'A PR changes the prompt from v1 to v2. The workflow evaluates v1’s saved responses, posts excellent scores, and passes its required check. Does this provide valid evidence for merging v2? What needs to change?'

   **Initial learner response:** 'No, we need to test v2 first, and evaluate it.'

   **Feedback:** Correct: generate v2 responses, then evaluate them against a versioned dataset and quality policy. The learner independently rejected stale-version evidence; fixed criteria and dataset details were tutor-supplied. No follow-up response.
