### Ordinary lesson checks

1. **Prompt:** “Your script accepts --learning-rate, trains successfully, and prints its validation loss—but never logs that loss with MLflow. Is it ready for a sweep to compare trials? What would you change, including the optimization direction?”

   **Initial learner response:** “No, we need to log it with MLflow using mlflow.log_metric("validation_loss", validation_loss). We also need to configure the primary metric, as well as the goal of the sweep.”

   **Feedback:** Correct script logging and metric matching. The learner did not specify a direction; the tutor supplied `goal="Minimize"` because lower validation loss is better. Do not count the direction as independently supplied in the initial answer.

2. **Context:** One `Choice` learning_rate=[0.001,0.01,0.1], grid, `max_total_trials=3`, `max_concurrent_trials=2`, `timeout=7200`; construction only, with separate submission shown.

   **Prompt:** “For this configuration, assuming all trials finish successfully within the timeout: 1. How many hyperparameter combinations does the grid contain? 2. Can all of them run simultaneously? 3. Does constructing sweep_job start training?”

   **Initial learner response:** “It's a grid, so it is based on the numbers in Choice, which is 3. It will only run 2 at a time. And it is not yet set to run.”

   **Feedback:** All correct. At most two run concurrently, subject to capacity; submission starts orchestration.

3. **Context:** Tutor numerical example: learning rates .001, .01, .1 with validation losses .42, .31, .38 and times 60, 90, 45 seconds; minimizing loss ranks .01, and secondary metrics do not automatically affect ranking.

   **Prompt:** “Suppose you wanted the sweep to rank trials by training time instead. Would simply logging a "training_time" metric be enough? What configuration would need to change?”

   **Initial learner response:** “No, we need to set the primary metric to "training_time" as well.”

   **Feedback:** Correct metric switch; direction was omitted, not explicitly wrong.

   **Follow-up prompt:** “if the objective is to choose the fastest trial, should the goal be "Minimize" or "Maximize"?”

   **Follow-up response:** “"Minimize" if you want to judge by a lower value.”

   **Feedback:** Correct prompted direction and explanation, after the tutor had already supplied the loss direction. This is not an independent initial full configuration.
